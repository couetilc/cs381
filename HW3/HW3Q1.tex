\section{Exercise 6.5.1}

\begin{quote}
    \noindent\texttt{\underline{is-half-connected($G$)}}: Given a directed graph $G=(V,E)$, returns True if the graph is half-connected, False otherwise.
    \begin{steps}
        \item Compute SCCs of $G$
        \item Make new graph, $H$, where each vertex represents a SCC and edges
        between those vertices exist if the original graph $G$ has at least one
        edge between those SCC.
        \item Topologically sort $H$ into $SCC_1$, $SCC_2$, ..., $SCC_k$
        \item Check if there is an edge between all consecutive $SCC$.
            \\
            $(SCC_i, SCC_{i+1}) \in E(H)$ for all $i = 1, ..., k - 1$
        \item Return True if all such edges exist
        \item Otherwise return False
    \end{steps}
\end{quote}

Proof: suppose the algorithm returns true. Then each SCC is linked to the next
in the order. For vertexes in different SCC, the vertex in the earlier sorted
SCC can reach the later SCC by following the chain of edges. If vertexes are in
the same SCC, they can reach each other by definition of SCC. Now by
contradiction, suppose a graph G is half-connected and the algorithm returns
False, implying at least one pair of osrted consecutive SCC does not have an
edge between them. Choosing one vertex from each of those SCC would produce a
pair of vertices that cannot reach each other, contradicting the half-connected
property so if a graph is half-connected, the algorithm will not return false.


Runtime:
\begin{steps}
    \item $O(|V| + |E|)$ to compute SCC of G
    \item $O(|E|)$ to build the new graph H
    \item $O(|V| + |E|)$ to perform topological sort
    \item $O(|V|)$ to check consecutive SCC pairs
    \\
    \\
    Total: $O(|V| + |E|)$ 
\end{steps}

\section{Exercise 5.13}

\begin{quote}
    \noindent\texttt{\underline{subs($k$, $h$, $v$)}}: Given parameters $k$, a
    set of bids (a bid is a tuple of $x$, the order price, and $y$, the inches of
    sub that fulfills the order), $h$, the inches of ham sub left, and $v$, the
    inches of veggie sub left, returns the maximum profit from selling the two
    sandwiches to the
    set of bidders.
    \begin{steps}
        \item If $k$ is empty, Return $0$
        \item $b = k[0]$
        \item if $b$ is a bid for ham and $h \geq b_y$
        \begin{steps}
            \item Return $Max($
            \\ \hphantom{    } $b_x - \texttt{cost($b_y$)} + \texttt{subs($k \setminus b$, $h-b_y$, $v$)}$, \textcolor{ForestGreen}{// Take the bid}
            \\ \hphantom{    } $\texttt{subs($k \setminus b$, $h$, $v$)}$ \textcolor{ForestGreen}{// Don't take the bid}
            \\ $)$
        \end{steps}
        \item if $b$ is a bid for veggie and $v \geq b_y$
        \begin{steps}
            \item Return $Max($
            \\ \hphantom{    } $b_x - \texttt{cost($b_y$)} + \texttt{subs($k \setminus b$, $h$, $v-b_y$)}$, \textcolor{ForestGreen}{// Take the bid}
            \\ \hphantom{    } $\texttt{subs($k \setminus b$, $h$, $v$)}$ \textcolor{ForestGreen}{// Don't take the bid}
            \\ $)$
        \end{steps}
        \item If $b$ is disjunctive and $h \geq b_y$ and $v \geq b_y$
        \begin{steps}
            \item Return $Max($
            \\ \hphantom{    } $b_x - \texttt{cost($b_y$)} + \texttt{subs($k \setminus b$, $h-b_y$, $v$)}$, \textcolor{ForestGreen}{// Take the ham bid}
            \\ \hphantom{    } $b_x - \texttt{cost($b_y$)} + \texttt{subs($k \setminus b$, $h$, $v-b_y$)}$, \textcolor{ForestGreen}{// Take the veggie bid}
            \\ \hphantom{    } $\texttt{subs($k \setminus b$, $h$, $v$)}$ \textcolor{ForestGreen}{// Don't take the bid}
            \\ $)$
        \end{steps}
        \item If $b$ is disjunctive and $h \geq b_y$
        \begin{steps}
            \item Return $Max($
            \\ \hphantom{    } $b_x - \texttt{cost($b_y$)} + \texttt{subs($k \setminus b$, $h-b_y$, $v$)}$, \textcolor{ForestGreen}{// Take the ham bid}
            \\ \hphantom{    } $\texttt{subs($k \setminus b$, $h$, $v$)}$ \textcolor{ForestGreen}{// Don't take the bid}
            \\ $)$
        \end{steps}
        \item If $b$ is disjunctive and $v \geq b_y$
        \begin{steps}
            \item Return $Max($
            \\ \hphantom{    } $b_x - \texttt{cost($b_y$)} + \texttt{subs($k \setminus b$, $h$, $v-b_y$)}$, \textcolor{ForestGreen}{// Take the veggie bid}
            \\ \hphantom{    } $\texttt{subs($k \setminus b$, $h$, $v$)}$ \textcolor{ForestGreen}{// Don't take the bid}
            \\ $)$
        \end{steps}
        \item Return $\texttt{subs($k \setminus b$, $h$, $v$)}$ \textcolor{ForestGreen}{// Unable to take bid}
    \end{steps}
\end{quote}

Given a ham sub $m$ inches long and a veggie sub $n$ inches long, find the
maximum profit from selling the subs to a set of $k$ bidders by calling
\texttt{subs($k$, $m$, $n$)}. The total number of calls that will be made is the
size of the powerset of the set of bids, so the runtime is $O(2^k)$.
